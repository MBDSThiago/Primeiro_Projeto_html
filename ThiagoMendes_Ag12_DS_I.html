Meus sites favoritos:Thiago Mendes


1- YouTube

O site que eu passo o maior tempo do meu dia, assistindo videos sobre video games ou algo relacionado. Link para o YouTube

2- Nexus Mods

Este site é um pouco mais específico, pois o utilizo quando quero baixar plugins ou arquivos que modificam aspectos dos jogos que estou jogando no momento. Por exemplo, é possível adicionar um dragão a um jogo de corrida, alterando a experiência original do jogo. Link para o Nexus Mods

3- Reddit

O Reddit e um site com varias comunidades, é uma plataforma online onde pessoas participam de comunidades para compartilhar informações,fazer perguntas, discutir assuntos e publicar conteúdos como textos, imagens, vídeos e links. Uso ele para comentar, participar e interagir com pessoas sobre varios assuntos, e até mesmo para solucionar dúvidas. Link para o Reddit

4- TikTok

O TikTok é uma plataforma que costumo utilizar durante o trajeto de ônibus para casa, após um dia cansativo de trabalho. Ele serve como uma ótima forma de distração e entretenimento durante o trânsito. Link para o TikTok

5- Pinterest

O Pinterest é uma plataforma que utilizo principalmente para buscar inspiração e visualizar imagens criadas por artistas. Também gosto de explorar artes feitas por fãs de heróis, desenhos animados e outros personagens. Link para o Pinterest
